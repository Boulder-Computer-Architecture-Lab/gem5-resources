# gem5-resources

This repo is contains some of the logic of the official [gem5-resources](https://github.com/gem5/gem5-resources), but with changes to update PARSEC, SPEC2017, and GAPBs to work with the latest versions of gem5.

# Disk Images

The following disk images can be created for gem5 v25.

* `parsec`: ~15.6 GiB 
* `spec2017`: ~27 GiB
* `gapbs`: ~8 GiB

Note that for SPEC2017, the proprietary image containing the benchmarks is needed and not provided in this repo for obvious reasons.
